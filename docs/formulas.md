# Fórmulas

Potência recomendada = consumo diário médio / (HSP média x Performance Ratio). Geração mensal = kWp instalado x HSP x dias x Performance Ratio x disponibilidade. VPL = soma dos fluxos descontados. ROI acumulado = economia líquida acumulada / CAPEX. LCOE = valor presente dos custos / valor presente da energia degradada.
